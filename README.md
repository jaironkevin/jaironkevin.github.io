# 🌐 Sitio web académico y profesional – Jairon Kevin Ojeda Silupu

Este repositorio contiene el código fuente de mi sitio web académico y profesional, desarrollado mediante **Quarto** desde **RStudio** y publicado a través de **GitHub Pages**.

🔗 Sitio web: https://jaironojeda.com/



## 1. Descripción general

El sitio web tiene como finalidad centralizar y difundir contenidos vinculados a la **estadística aplicada**, el **análisis de datos** y la **investigación científica**, integrando producción académica, proyectos aplicados, recursos técnicos y servicios profesionales en un entorno web moderno, reproducible y mantenible.

El proyecto responde a criterios de rigor metodológico, claridad expositiva y organización temática, alineados con buenas prácticas académicas y profesionales.



## 2. Origen del diseño y desarrollo del proyecto

La arquitectura inicial del sitio tomó como referencia técnica un repositorio público desarrollado por **Rob J. Hyndman**, utilizado exclusivamente como **punto de partida estructural** para comprender la implementación de sitios web académicos con Quarto.

A partir de dicha base inicial, el sitio fue objeto de un **proceso integral de rediseño y personalización**, que incluyó:

- Rediseño completo del estilo visual (paleta de colores, tipografías e identidad gráfica)
- Reestructuración de la navegación y jerarquía de contenidos
- Incorporación de secciones propias (servicios, portafolio, publicaciones, software)
- Desarrollo de estilos CSS personalizados
- Producción y organización de contenidos originales

En su estado actual, el sitio constituye un desarrollo **autónomo, original e independiente**, tanto en diseño como en contenido, y no corresponde a un fork ni a una réplica directa del repositorio de referencia.



## 3. Estructura principal del repositorio

```text
├── blog/              # Entradas de divulgación y análisis
├── portafolio/        # Proyectos aplicados
├── publications/      # Producción académica
├── servicios/         # Servicios profesionales
├── software/          # Recursos y desarrollos técnicos
├── _quarto.yml        # Configuración global del sitio
├── index.qmd          # Página principal
├── styles.css         # Estilos personalizados
```
